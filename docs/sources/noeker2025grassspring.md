# noeker2025grassspring: How the spring of the GRASS small-body gravimeter is designed and built (Noeker, Ritter, Van Ransbeeck, Karatekin, CEAS Space Journal 17(5):755-768, 2025)
Abbreviations in the title: CEAS = Council of European Aerospace Societies.

## Claim
Describes the GRAvimeter for small Solar System bodies (GRASS) cantilever spring. The spring allows "measurements at arbitrary instrument orientation". Two orthogonal springs are rotated so that each deflection is a sinusoid; this gives the 3-D vector and bias rejection.
