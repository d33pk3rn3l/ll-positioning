# archinal2018wgccre: IAU WGCCRE report 2015 (Archinal et al. 2018)

## Claim
The 2015 IAU WGCCRE report removes the low-precision series for the Moon's orientation and separates a reference radius for cartographic use from one for orthoprojection and geophysical use (Moon, Titan). It repeats the recommendation to make controlled cartographic products.
