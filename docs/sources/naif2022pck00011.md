# naif2022pck00011: The NASA SPICE constants file for body size and rotation, Moon part (NAIF file pck00011.tpc, N. Bachman, 27 December 2022)
Abbreviations in the title: NASA = National Aeronautics and Space Administration; NAIF = Navigation and Ancillary Information Facility.

## Claim
The NAIF space geometry toolkit (SPICE) text kernel that implements the International Astronomical Union (IAU) Working Group on Cartographic Coordinates and Rotational Elements (WGCCRE) reports. For the Moon it states that the 2015 report gives no rotational elements, and keeps the 2009 values for the IAU_MOON (approximate Mean Earth/polar axis frame (ME)) frame.

## Numbers (with units and conditions)
Format: value | product | frame realization | statistic type. "not stated" = the source does not say.
- Quote: "The IAU report [1] no longer provides rotational elements for the Moon. Data in this file are from [3]." [1] = Archinal et al. 2018 (2015 report); [3] = Archinal et al. 2011 (2009 report).
- Quote: "The values shown below are those from the 2009 IAU report. The 2015 report does not provide orientation data for the Earth or Moon."
- "BODY301_PM = ( 38.3213 13.17635815 -1.4D-12 )" (deg, deg/day, deg/day^2) | IAU 2009 model | IAU_MOON (approximate ME) | no uncertainty given.
- "BODY301_POLE_RA = ( 269.9949 0.0031 0. )", "BODY301_POLE_DEC = ( 66.5392 0.0130 0. )" | same.
- "BODY301_RADII = ( 1737.4 1737.4 1737.4 )" (km), "Values are unchanged in the 2015 IAU report."
- Accuracy note in file: orientation models stated by the IAU report "to be accurate to 0.1 degree" (general statement, line 256; not Moon-specific in the part I read).
- Mean sidereal rotation [derived]: 360 / 13.17635815 = 27.321662 d; rate 2.6617e-6 rad/s; horizontal component at 14.1° N 2.58e-6 rad/s = 0.53 °/h [derived] (matches prof-geodesy's 0.53 °/h).

## Height reference
Sphere 1737.4 km.

## Application to a walking quadruped on the Moon (LunarLeaper)
Primary-implementation source for the Moon rotation rate. For precise work the file itself says to use MOON_ME/MOON_PA from the JPL Development Ephemeris (DE) frame kernel (naif2025moonfk), not IAU_MOON. Also confirms one point of the Archinal 2018 body text: the 2015 report has no Moon orientation model.
